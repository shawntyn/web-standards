# 一手参考

当前实现按 lockfile 使用既有依赖版本，未进行升级。

- [pnpm workspace](https://pnpm.io/workspaces)：应用与共享包的依赖边界。
- [Next.js 项目结构](https://nextjs.org/docs/app/getting-started/project-structure)：当前只有 apps/web 一个应用。
- [Next.js 动态路由](https://nextjs.org/docs/app/api-reference/file-conventions/dynamic-routes)：`[slug]` 与异步 params。
- [Next.js connection](https://nextjs.org/docs/app/api-reference/functions/connection)：请求时渲染。
- [Server 与 Client Components](https://nextjs.org/docs/app/getting-started/server-and-client-components)：服务器读取与客户端渲染边界。
- [Tailwind source detection](https://tailwindcss.com/docs/detecting-classes-in-source-files)：workspace 组件的静态类名扫描。
- [官方 json-render](https://github.com/vercel-labs/json-render)：Spec、catalog、registry 与 Renderer。

实际阅读路径以 [中文阅读指南](reading-guide.md) 为准；旧验证日志仅代表历史版本，不能作为当前结果。
