# Named slots · 特殊交互扩展

插槽是明确声明的扩展点，不是逃离 JSON 协议的后门。特殊组件 CapacityPlanner 在 catalog 声明 props，在 registry 绑定本地实现，然后通过 Card 的 footer 插槽引用。

## Props 与边界

- CapacityPlanner.initial：1 到 100 的数字。
- Card.slots.header / footer：节点 ID 数组；默认内容仍使用 children。
- 只有开发者注册的组件类型可用。不接受运行时组件源码、模块路径、HTML 字符串或任意函数。

## 无障碍

滑块有真实 label 与唯一 ID，支持方向键和键盘焦点。多实例不能复用固定 DOM ID。特殊组件仍需遵守基础组件库的键盘、状态和触控要求。
